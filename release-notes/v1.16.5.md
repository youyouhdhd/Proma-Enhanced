# v1.16.5 — Codex 登录与账号模型目录

本版修复跨设备 Codex 授权后的回填流程，并让模型选择器直接读取当前 ChatGPT 账号可用的 Codex 模型。

## ChatGPT (Codex)

- 浏览器授权完成后，即使另一台设备上的 `localhost` 回调页无法连接，也可把地址栏的完整回调网址粘贴回发起登录的 Proma。
- 「拉取模型」和 OAuth 登录后的自动拉取会通过当前账号凭据向 Codex 服务读取可见模型目录。
- 新模型可以直接进入模型列表和 Pi runtime，不必为每个模型发布一份静态 ID 列表；上下文窗口、输入模态和推理档位使用服务端信息。
- 目录按账号缓存；请求失败会显示错误并保留已有列表。更新目录时保留用户现有模型开关和已知模型的兼容信息。
- 已过期的 OAuth 凭据会按现有刷新流程续期；返回表单的轮换凭据，防止保存时覆盖新 token。
