# v1.17.2 — 执行过程独立滑条

Agent 执行过程区现在拥有与外层会话滚动条相互独立的可见滑条，长思考与长执行过程的翻阅不再需要来回拖动整条会话。

- 流式期间的过程视口显示纤细滚动条（此前为隐藏式滚动），可直接拖动定位；拖离底部即暂停自动跟随，拖回底部自动恢复跟随最新输出。
- 历史消息中展开"执行过程"后，内容被限制在最高 `min(50vh, 480px)` 的独立视口内滚动，短内容不产生滚动条、不改变布局。
- 拖动滑条翻阅过程中若流式结束，不再触发 3 秒倒计时自动折叠，保留当前阅读位置；跟随到底部时仍照常自动收起。
- 滚动意图判别：程序化跟随动画帧与用户滚动分离，避免滑条拖动与自动跟随互相拉扯；预留滚动条 gutter 防止滚动条出现时内容横向跳动。
- 视口补充 `role="region"` 与 aria 标签，聚焦后支持方向键 / PageUp / PageDown / Home / End 键盘滚动。

根工作区/Electron：1.17.2。
