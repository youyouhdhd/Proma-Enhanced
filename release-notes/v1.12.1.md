# v1.12.1 — 上游同步与运行时依赖修复

本版将已合并上游的开发线整理为正式版本，并修复旧安装遗留的 `node_modules/.bun/node_modules` 可能覆盖当前 hoisted 依赖的问题。它包含上游 35 个提交、Pi 0.85.1，以及 V13 独立 ngrok 与稳定多项目 Connector 能力。

- 运行时同步改为从当前 hoisted `node_modules` 及包自身依赖解析，不使用残留的全局虚拟目录覆盖当前安装。
- 新增隔离回归测试，验证当前版本与旧虚拟版本同时存在时，默认同步选择当前版本。
- 应用版本为 1.12.1；shared 保持 0.7.0，根工作区保持 1.1.1，Pi 保持 0.85.1。
- 产品代码基线为 `492be976`，上游合并提交为 `f72fa19c`，上游基线为 `f99edbdb`；`v1.12.1` 标签包含本次发布元数据提交。

## 主要更新

- **上游同步**：合入上游 35 个提交，包含 Pi Agent SDK 0.85.1、GitHub Copilot 订阅登录与额度、MCP OAuth 管理、Exa Search、计划预览、跨工作区 Automation、Markdown/Skills/侧栏和更新缓存修复。
- **Fork 能力保留**：保留 Codex OAuth 会话、显式浏览器授权、自建渠道推理档位、QuickAsk、V13 Managed/System/External Existing ngrok、稳定 Connector、项目热更新和权限隔离。
- **运行时依赖**：同步脚本只从当前 hoisted `node_modules` 解析依赖，避免残留 `.bun/node_modules` 将 Pi 或其它运行时降级；新增隔离回归测试。
