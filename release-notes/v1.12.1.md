# v1.12.1 — 运行时依赖同步修复（未发布）

在 v1.12.0 上游合并后的本地同步中，发现旧安装遗留的 `node_modules/.bun/node_modules` 可能仍指向过期 Pi 包。打包脚本优先读取该目录时，即使当前 hoisted 安装已升级，仍可能复制错误版本。

- 运行时同步改为从当前 hoisted `node_modules` 及包自身依赖解析，不使用残留的全局虚拟目录覆盖当前安装。
- 新增隔离回归测试，验证当前版本与旧虚拟版本同时存在时，默认同步选择当前版本。
- 应用版本递增为 1.12.1；shared 保持 0.7.0，Pi 保持 0.85.1。
- 此版本用于开发分支，不创建新 Release。正式发布版本仍为 v1.11.0，使用干净 CI 环境生成的跨平台附件。

验证：700 项测试、全 workspace 类型检查、Electron 构建通过；Windows x64 解包构建中的应用版本、Pi 0.85.1、native 模块及 Local/Public MCP 冒烟通过。
