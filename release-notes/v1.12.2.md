# v1.12.2 — Fork Release 历史排序修复

本版修复 Enhanced Fork 的版本历史来源和排序，并清理已被补丁版取代的旧草稿 Release。

- 应用内更新与版本历史统一读取 `youyouhdhd/Proma-Enhanced`，不再读取上游或旧仓库。
- 先过滤草稿和不需要的预发布版本，再按完整 SemVer 从大到小排列。
- 首次请求取得足够候选，避免只请求三条后过滤导致版本历史缺项。
- “最新”标记来自 GitHub Latest Release，不再直接把数组第一项视为最新。
- GitHub 上的 `v1.10.0`、`v1.9.0` 过期草稿 Release 已删除，对应 Git Tag 保留。

版本：Electron 1.12.2；shared 0.7.0；根工作区 1.1.1；IPC Bridge 13。

验证：703 项测试通过、全 workspace 类型检查和 Electron 构建通过；真实 Fork API 返回的正式版本与预发布版本均按 SemVer 降序，GitHub Latest 为 v1.12.1（发布 v1.12.2 后由 GitHub 更新）。
