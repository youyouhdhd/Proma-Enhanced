# v1.12.0 — 上游同步开发版本（未发布）

在正式发布 v1.11.0 后，将上游 `proma-ai/Proma` 的 35 个提交合入开发分支。同步范围为 `7a3721d7` 至 `f99edbdb594407ab190b97ae073889c5d96637ab`，对应上游应用 0.19.53。当前稳定下载仍为 [v1.11.0](https://github.com/youyouhdhd/Proma-Enhanced/releases/tag/v1.11.0)，本记录不代表新增 GitHub Release。

## 合入的主要更新

- Pi Agent SDK 升至 0.85.1，并同步上游补丁与依赖锁文件。
- GitHub Copilot 订阅登录、模型目录及额度/重置时间展示。
- 工作区 MCP 受控配置、OAuth 管理与 Exa Search 连接入口；移除上游已退役的内置搜索/生图工具入口。
- DeepSeek Flash 思考深度与 1M 上下文适配，以及上游的模型上下文修正。
- 计划文档只读预览与审批、Agent 本地文件/图片路径修复、跨工作区定时任务。
- Skills 关闭与移除状态、Markdown 表格/查找/预览、Obsidian 双链和侧栏交互修复。
- 更新安装包缓存的安全清理与保留策略。

## Fork 保留与合并处理
