# v1.17.3 — 推理档位钳制修复与渠道模型增强

自建渠道模型的自定义推理档位现在会按你在渠道里声明的原样发送，并新增上下文窗口设置与档位拖拽排序。

- **修复 xhigh/max 档位被静默降级为 high**：此前在渠道里声明 xhigh 或 max 档位且未填写映射值时，Pi 运行时会把这两个扩展档位视为不支持并自动钳制到 high，导致部分后端（只接受 none/low/medium/xhigh）返回 400。现在未配置映射的 xhigh/max 档位在注册时自动补自映射，选择什么就发送什么；已显式配置的映射保持优先。
- **渠道模型自定义上下文窗口**：渠道设置的推理配置面板新增「上下文窗口」输入（8,000 – 10,000,000 token），留空则按模型 ID 推断。自定义值同时作用于 Pi 运行时注册的窗口（影响自动压缩时机）和会话进度环分母，方便对接目录外模型或网关侧裁剪过窗口的部署。
- **推理档位拖拽排序**：档位行左侧新增拖拽手柄，拖动时显示插入指示线，排序结果即时生效并自动保存；档位顺序即会话选择器的展示顺序。

根工作区 1.17.2 / Electron 1.17.3 / shared 0.12.4。
