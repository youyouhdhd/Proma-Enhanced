## 新增

### PROMA MCP Server（ChatGPT Web 可调用本地能力）

- 标准 MCP Server（Streamable HTTP，`POST /mcp`），默认仅监听 `127.0.0.1`，端口可固定或自动选择；
- 工具集：`workspace_info` / `list_files` / `read_file` / `search_text` / `find_files` / `git_status` / `git_diff`（只读），`write_file` / `edit_file` / `shell_execute`（完整模式需显式开启）；
- 安全：resolve + realpath 双重路径守卫（路径越界 / symlink 逃逸一律拒绝）、Shell 默认关闭且 cwd 限定工作区、可选 Bearer Token 认证；
- 会话：按 `Mcp-Session-Id` 管理，空闲 30 分钟回收，应用退出全部关闭；
- 隔离：MCP 工具执行绝不触发 Pi / Codex / 任何模型调用；
- 设置页：机器人连接 Hub 新增「MCP Server」页（启停 / 端口 / 工作区 / 访问模式 / 认证 / 工具列表）。

### Codex 手动 OAuth 登录

- 授权 URL 展示 / 复制 / 打开浏览器（自动打开失败不影响手动登录）；
- 支持粘贴完整回调 URL（`http://localhost:1455/auth/callback?code=…&state=…`）完成登录，适用于远程 / 沙盒浏览器场景；
- code 解析、state 校验与 token 交换全部由 Pi 完成；自动回调与手动提交竞速安全（首次生效）。
