# v1.13.1 — Agent 执行租约来源隔离

本补丁版修复 v1.13.0 引入的执行守卫边界问题：ChatGPT Direct 工具和 PROMA Agent 动作现在使用独立的租约来源，修改其中一方策略时不会错误保留或撤销另一方的正在执行操作。

- `RemoteExecutionGuard` 记录 `direct` / `agent` 来源，并按对应策略重新校验。
- Agent Action 继续受全局 Sharing、工具开关、Workspace 权限、Agent 策略、Scope、路径校验、Abort、并发和速率限制约束。
- 不移动 v1.13.0 标签；保留 v1.13.0 的 ChatGPT 能力发现、实时权限预检、本地审批和 Agent Action 功能。

版本：Electron 1.13.1；shared 0.8.1；根工作区 1.1.1；Bridge 13；Pi 0.85.1。

验证：新增来源隔离 BDD 测试；706 tests pass / 0 fail、全 workspace typecheck、Electron build、`bun install --frozen-lockfile` 通过。
