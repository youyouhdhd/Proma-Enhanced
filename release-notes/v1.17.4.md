# v1.17.4 — 终端用户接管与等待状态修复

Agent 操作终端时，可以明确请求你接管输入、登录或确认。聊天区会显示“等待你操作终端”卡片；你在原终端完成操作后点击“已完成，继续”，Agent 从原任务续跑并检查终端输出。

- **终端接管卡片**：支持打开并聚焦原终端、完成后继续、问题反馈和取消任务。卡片回复不会写入终端，密码等输入仍留在终端。取消任务停止 Agent，终端保留，可手动 Ctrl+C 中断程序。
- **明确的等待状态**：问答、终端接管、权限确认与计划审批等待期间，消息区显示相应状态；卡片不会藏入折叠的执行过程。
- **交互恢复**：界面重载后恢复未决问答与权限请求，并对实时事件/快照去重，防止已处理卡片复活。
- **隐藏终端输出修复**：输出确认改由主进程完成，切换标签或隐藏终端不会再阻塞后台输出采集与退出通知。
- **收尾与校验**：终端退出、关闭或运行时异常会解除接管等待；验证终端归属，防止跨会话绑定，反馈失败保留内容并允许重试。
- **长时间操作**：终端接管持续等待用户完成操作，不再受到普通问答 15 分钟超时影响；可随时取消任务。

终端接管由模型主动调用工具触发；本版不保证自动识别所有终端输入提示，也不会因一段时间没有输出就断言程序在等待。用户点击完成表示操作声明，Agent 仍需核验程序结果。

根工作区 / Electron 1.17.4；shared 0.12.5。
