# v1.17.0 — 上游体验更新与渠道兼容保留

本版审查并合入上游主分支 `86d9dfb5`，在接入新功能的同时，保留 Enhanced 的账号在线模型发现、存量渠道和权限边界。

## 新增与修复

- 会话文件变更列表支持整体折叠；“更早”分组默认收起，本轮修改保持易见。Git 目录增加文件管理器快捷入口。
- 右侧工作区展开或调整宽度时，自动重新定位活动标签，避免新打开的浏览器页藏在可视区域外。
- 小米渠道增加 MiMo 2.6 Pro、Flash 和 Pro UltraSpeed 候选；精确匹配对应型号的窗口和输出能力，存量模型名称及启用状态保持不变。
- 补充 GPT-6 Sol/Luna 和 Astra 家族的推理与 Fast Mode 兼容，Codex 服务端返回的账号能力仍优先。
- Pi runtime 升级到 0.87.1，保留现有重试补丁。

## 合并取舍

- Codex「拉取模型」继续访问当前账号的在线目录；不会被上游静态目录逻辑替换。
- 保留 OpenCode Go、火山方舟 Agent/Coding Plan 的配置、密钥与请求适配，不执行上游删除已有渠道的迁移。具体模型和额度仍以供应商账号权限为准。
- 保留 Enhanced 的跨设备 OAuth 回填、自建渠道推理档位、Global Registry、MCP Sharing 和独立 Release 来源。
- 仅合并已进入 `upstream/main` 的 12 个提交；详细记录见 [Fork 维护指南](../docs/fork-maintenance.md)。
