# v1.16.2 — Proma Coach Enhanced Fork 使用指导同步

本补丁版让 Proma 自带的使用顾问理解 Enhanced Fork 已经提供的产品能力，避免继续按官方旧心智模型指导用户复制项目 Skill、误判 ChatGPT Agent 权限或混淆当前模型与实际执行模型。

- 保留 `proma-coach` 原有 A–F 根因分类、四步工作流、知识维护规则和示例结构。
- 新增 QuickAsk、Global Registry、Project Overlay、Required/Default、Effective Inspector、MCP Sharing、Direct Tool、Agent Delegation、远程连接、每轮模型归因和长运行导航的稳定路由规则。
- 新增按需读取的 Enhanced 能力地图，集中记录模式选择、能力范围、Connector 诊断和安全不变量；普通 Coach 介入不会加载整份参考。
- 明确禁止自动 Promote、绕过 Required、泄露 Secret、把内部 Agent 与外部 Connector 混为一谈，以及用当前模型改写历史 executed model。
- 默认 Skill 版本升级到 1.0.14；应用启动后，版本同步机制会把新版 Skill 及 reference 更新到本地默认 Skills 和工作区。

版本：根工作区 / Electron 1.16.2；shared 0.12.0；session-core 0.2.0；Pi runtime 0.86.1。

本版本是独立开发提交，不移动已发布的 v1.16.1 标签。验证：733 tests pass / 0 fail；全 workspace typecheck、frozen lockfile、Electron build、Renderer 源码边界与产物 smoke 通过。Proma 的 `parseSkillVersion` 已确认读取 1.0.14；Codex 通用 Skill validator 因不接受 Proma 专用顶层 `version` 字段而不适用，未为通过外部校验器破坏应用升级协议。
