# v1.13.0 — ChatGPT 能力发现与 PROMA Agent 动作委派

本版让 ChatGPT 网页端在首次连接 PROMA 时获得明确的 MCP 服务级能力说明，并增加实时权限预检与可选的 PROMA Agent 动作模式。

- MCP Discovery / initialize 返回 PROMA `instructions`，说明可见工具、`workspace_list` 预检和 Direct Tool 与 Agent Delegation 的区别。
- 工具目录补充标题、输出 schema 与安全 annotations；`workspace_list` 返回 Direct 能力、Agent 状态和每个 Workspace 的有效权限。
- Discovery fingerprint 现在包含 instructions 与工具 metadata，能力说明变化会提示 ChatGPT Refresh；项目和权限热更新不改变 Connector URL。
- 共享配置升级到 v3，旧配置默认迁移为 Agent 只读分析，不扩大既有权限。
- 保留 `proma_task_start` 只读分析入口，新增可选 `proma_action_start`；动作 Agent 支持本地审批或高级 Direct 模式，任务固定到单个 Workspace。
- Agent 动作使用独立 `actionTools`，逐次重新校验 Scope、Root、Workspace 权限、策略、速率和并发；权限撤销会中止任务。
- 新增本地任务批准/拒绝 IPC 与设置页审批操作，任务结果返回结构化状态、变化文件、警告和稳定错误码。
- Shell 变化无法完全追踪时返回明确 warning，不记录任务 instruction、文件内容或凭据。

版本：Electron 1.13.0；shared 0.8.0；根工作区 1.1.1；Bridge 13；Pi 0.85.1。

验证：706 tests pass / 0 fail；专项 MCP / sharing / transport 测试、全 workspace typecheck、Electron build 和 `bun install --frozen-lockfile` 全部通过。
