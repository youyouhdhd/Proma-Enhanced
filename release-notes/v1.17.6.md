# v1.17.6 — 最终答复保护与协议兼容修复

Agent 不再将“只有思考或工具过程，没有最终正文”当作成功完成。

- **一次安全补答**：原任务真正结束后检查最终主线回复；缺正文时依据已有结果最多补答一次，移除全部工具声明，不重新执行工具。界面显示“正在整理最终答复，最多等待 60 秒”。停止或追加新消息会取消旧补答。
- **明确失败与历史提示**：补答仍无正文时标记执行失败，保留过程。历史缺正文回合在折叠过程外显示常驻提示；CLI 与导出采用相同判定。外部任务入口收到失败状态。
- **V4.1 参数与思考回放**：明确识别已验证的 Flash 别名，按所选档位发送 effort；仅方舟 Anthropic V4.1 组合允许空签名思考原样回放，其他模型保持原策略。
- **异常流检查**：Anthropic SSE 的缺块、错类型、重复活动索引及未闭合块明确报协议错误，诊断只记录事件计数等元数据。
- **保留字面标签**：新 Pi 结构化消息中的 `<think>` 示例仍作为正文；历史前导标签仅在闭合时解析，未闭合终态保留原文并提示。

补答的 60 秒上限适用于模型请求；本地问答、权限、计划审批和终端接管继续等待用户回复，没有自动交互超时。补答不能保证上游一定返回正文，失败时不会把思考内容猜测为最终答案。

根工作区 / Electron 1.17.6；shared 0.12.6；session-core 0.2.1；Pi 0.87.1（扩展既有补丁）。

验证包括全量自动测试、类型检查、生产构建、真实方舟合成协议请求和 Windows 包内 Agent runtime/ConPTY 冒烟。界面已做组件静态状态测试，实际点击及深浅主题视觉验收尚未完成。
