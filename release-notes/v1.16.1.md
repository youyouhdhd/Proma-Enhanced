# v1.16.1 — 统一 Agent 能力层与上游运行时升级

本版在保留 Enhanced Fork 的 ChatGPT 能力发现、Agent 动作委派、Codex OAuth、自建模型推理档位和独立 Release 来源的基础上，同步上游主分支并建立统一的 Agent 能力解析与管理入口。

## 全局 Agent 能力

- 新增 Global Registry 与 Project Overlay，统一管理 Skills、MCP Servers、Instructions 和工具拒绝策略。
- Resolver 按 Global Required → Global Default → Project → Session → Turn 合并；Required 约束在所有 Overlay 后重新执行，工具权限采用 Deny-Wins。
- 缺失 Skill/MCP 不会被静默丢弃，Effective Inspector 会显示来源、Required、Ready/Error/Missing 和稳定配置 hash。
- 设置新增“Agent 能力”页面，支持全局开关、默认/必需状态、项目继承差异、迁移候选、显式 Promote 和受控移除。
- 关闭全局能力解析会立即恢复原 Workspace 加载行为；空 Registry 与旧版本行为等价。

## 迁移与安全

- Skill 只有在用户显式 Promote 后才复制到应用级全局目录，项目 Overlay 随后引用 Global ID。
- MCP Promote 只保存非敏感定义；Header/env 值不会进入全局 JSON 或项目 Overlay，凭据只在主进程 Keychain 内复制到独立作用域。
- 同名但定义不同的 MCP 只报告冲突，不自动覆盖；Required 条目不能通过 UI 或 IPC 删除。
- 移除全局条目会清理相关 Overlay 引用并恢复原项目能力，同时保留 Skill 实体和 Keychain 凭据，便于后续恢复。

## 每轮实际模型归因

- Agent 每轮运行持久化 requested、executed 和 fallback 快照，避免会话切换模型后改写历史显示。
- Desktop、历史记录、会话预览、上下文统计和飞书终态卡片统一使用实际执行模型；尚未确认执行模型时不再推测。

## 长运行导航

- 用户暂停阅读时显示“最新 · N”，按稳定消息组累计，回到底部或切换会话后清零。
- 自定义滚动条增加 ARIA 语义，并支持 Home、End、方向键和 Page Up/Page Down。
- Reduced Motion 环境使用即时滚动；2,000 次暂停增量基线无需引入第二套导航状态或无证据虚拟化。
