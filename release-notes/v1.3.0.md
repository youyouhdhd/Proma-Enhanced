## 重构：OpenAI Tunnel Client 产品化

把 `tunnel-client` 从「用户必须自行理解、安装、配置和运行的 CLI」变成 PROMA 自动管理的内部连接组件：

- **三种来源模式**：`managed`（PROMA 自动安装到 `~/.proma/tools/openai-tunnel-client/<version>/`，无需管理员权限、不污染 PATH）/ `custom-path`（指定本机已有可执行文件，支持文件选择器）/ `system-path`（从系统 PATH 查找，高级）；
- **删除任意命令行**：不再支持 `clientCommand` 任意 Shell 表达式；旧配置读取时一次性迁移（绝对路径 → custom-path，`tunnel-client` → system-path，含 `&& | > <` 等 Shell 元字符的旧配置不再执行，回退 managed 并提示重新选择）；
- **Windows 修复**：全部进程一律 `shell: false` 直接 spawn——命令不存在得到明确的 ENOENT 而不是 cmd.exe 中文代码页乱码；stdout/stderr 使用 `StringDecoder` 跨 Buffer 安全解码；检测判定必须 `--version` 退出码为 0，不再「进程能创建 = 已安装」；
- **拒绝 URL 下载执行**：程序位置只接受本地文件；粘贴 https 地址会得到「请使用本地程序位置或安装官方组件」的提示；自动安装仅允许官方 Release 元数据并做 SHA-256 校验；
- **真实 readiness**：删除「进程存活 8 秒 = 已连接」启发式。启动后经 health URL 文件发现端口 → 轮询 `/healthz`（进程活着）→ `/readyz`（Tunnel + MCP 就绪）→ 才显示「已连接」；
- **状态机 + 实时推送**：`not-installed / needs-config / preflight / starting / waiting-ready / connected / stopping / stopped / error` 全程经 `mcp-tunnel:state-changed` 推送到渲染层，不再有永久「正在建立连接…」；
- **结构化诊断**：`tunnel-client doctor` 结果解析为检查项列表（本地 MCP / 程序 / 配置 / 网络 / Runtime Key），技术详情默认折叠；15 个稳定错误码（`TUNNEL_CLIENT_NOT_INSTALLED` / `RUNTIME_KEY_UNAUTHORIZED` / `READY_TIMEOUT` / `TUNNEL_CLIENT_EXITED` 等）都带「发生了什么 + 下一步」；
- **自动恢复连接**：可选「PROMA 启动后自动恢复 ChatGPT 安全连接」开关，默认关闭。

## 重构：ChatGPT Web Setup 向导

- 页面顶部明确三平台分工：PROMA（项目 + 本地连接）→ OpenAI Platform（Tunnel + Runtime Key）→ ChatGPT Web（MCP App），并给出「获取位置 → 获取内容 → 粘贴到」对照表；
- 八步向导：项目授权 → 本地 MCP（明示地址无需复制）→ Tunnel Client 准备 → 创建 Tunnel → 创建 Runtime API Key → 「检查配置并连接」（preflight 逐项检查后自动启动）→ ChatGPT 创建 App（明示三样东西不需要填）→ 第一次测试（复制测试提示词 + 「已收到来自 ChatGPT 的 MCP 请求 · 最近工具」实时显示）。

## 修复：Codex OAuth 默认行为（显式浏览器动作）

确立新原则：**「登录」按钮只负责准备授权信息，绝不打开浏览器**：

- 点击「用 ChatGPT 登录」→ 对话框立即出现 → 生成并显示授权网址 → 停下等待用户选择「复制授权网址」或「在浏览器中打开」；全程系统浏览器调用次数为 0，直到用户明确点击；
- 新增专用 IPC `codex-oauth-open-browser`：Renderer 只传 `sessionId`，Main 按当前会话解析官方授权地址并校验 https 协议后打开——Renderer 无法借该接口打开任意 URL；
- 「在浏览器中打开」可重复点击（浏览器开错 / 关掉可以再开），打开失败只提示并保留复制入口，不终止 OAuth 会话；
- Device Code 流程同样不自动打开浏览器：展示授权地址 + 设备码 + 复制按钮，二维码出现也不触发浏览器；
- 会话快照移除 `autoOpenBrowser` / `browserOpened` 业务字段；重试登录、会话恢复、URL 过期重建同样不会自动弹浏览器。
