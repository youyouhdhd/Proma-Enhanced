# v1.6.0 — V7：ChatGPT MCP Modern Discovery 兼容（server/discover / 直方图观测 / Discovery 管线）

- 发布日期：2026-09-08
- 基准上游：`proma-ai/Proma` `7a3721d7`（本版本为纯二次开发功能版本）

> **关于本 Fork**：本仓库是 [proma-ai/Proma](https://github.com/proma-ai/Proma)（官方上游）的增强 Fork，独立版本号自 v1.0.0 起。功能变更清单见 [docs/fork-maintenance.md](../docs/fork-maintenance.md)。

## 背景

v1.5.0 实测：Doctor exit 0、/readyz 200、诊断窗口收到 14 条 MCP 请求，但 tools/list 为 0——请求已经到达 PROMA，却没有任何 Tool Discovery。V7 判断问题收敛到现代 MCP Discovery 阶段（如 `server/discover` 在 tools/list 之前发出，而 PROMA 基于 SDK v1.x 不认识该方法，返回 -32601 导致 ChatGPT 终止 discovery）。

## P0-1：请求观测升级——先看清 ChatGPT 发了什么（V7 §5-§7/§19-§21）

- `PromaMcpRequestTrace` 扩展：非敏感请求头（content-type / accept / mcp-protocol-version / mcp-method / mcp-name / user-agent）与 JSON-RPC error code（HTTP 200 也可能携带 RPC error，如 -32601）；
- 新增 `PromaMcpMethodStats` 方法直方图：total / methods / statuses / discoverCount / initializeCount / toolsListCount / toolsCallCount / unknownCount；
- 设置页「最近 MCP 请求」时间线显示 RPC 错误码；诊断报告增加 RPC Method / HTTP 直方图。

## P0-2：实现 server/discover 现代 Discovery 握手（V7 §3/§12-§14）

- 无会话 POST 的 `server/discover` 在进入 SDK v1 Server 之前被现代协议层拦截并直接响应：`protocolVersions`（2026-07-28）/ `capabilities.tools` / `serverInfo`（Proma MCP），并携带 `Mcp-Protocol-Version` 响应头；
- 该实现为隔离的 compatibility shim（`protocol/modern-handler.ts`），带明确 TODO(SPIKE-MCP-SDK-MODERN) 与删除路径——升级现代 SDK 后替换为官方 schema/handler；
- 未知方法（如 `foo/bar`）仍返回标准 JSON-RPC -32601 并进入 trace。

## P0-3：GET /mcp 协议行为对齐（V7 §16）

- 无会话 GET /mcp 从 404 改为 **405 Method Not Allowed（Allow: POST）**；带有效会话的 GET 仍走 legacy SSE。

## P0-4：Connector 诊断结论重写（V7 §8/§26）

- 新增 **CASE B-DISCOVER**（server/discover 已发出但响应失败：问题在 PROMA Discovery 协议层）与 **CASE B-HANDSHAKE**（discover 成功但未进 tools/list：检查 protocol negotiation / capabilities）；
- 诊断报告新增 Discovery Pipeline 四步（① Tunnel Request → ② Server Discovery → ③ Tool Discovery → ④ Tool Call）与方法直方图；
- `classifyConnectorConclusion` 抽为纯函数便于回归测试。

## P1：Doctor 降噪与 Codex 插件降级（V7 §27-§28）

- Doctor 只直接显示关键项（Tunnel ID / Runtime API Key / PROMA MCP / Health Listener 等），官方入口与扩展检查折叠；
- `codex_plugin SKIP` 降级为「Codex Tunnel 插件（可选，仅 Codex CLI 需要）」，不影响 ChatGPT Connector。

## 测试与工具

- 集成测试新增 5 项（真实 HTTP）：`server/discover` 返回协议版本/capabilities/serverInfo、discover 后 tools/list 仍可用、GET 405、未知方法 -32601、bearer 401/带凭据 200（V6）；
- 新增 `test:mcp-modern` 命令与 `scripts/test-modern-mcp-discovery.ts`：对运行中的 Local MCP 模拟 server/discover → tools/list → workspace_list 并输出 ✓/✗ 报告；
- typecheck 六包全绿；621 测试全过；`build:main / build:preload / build:renderer`、`check:renderer-boundaries`（418 文件）、`smoke:renderer-dist`（780 文件）通过。
