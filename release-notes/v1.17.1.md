# v1.17.1 — 手动检查更新与待安装包替换

修复旧版本安装包已就绪时无法主动检查新版的问题。

- “设置 → 关于 Proma → 软件更新”始终保留“检查更新”按钮；已有安装包就绪时也可以复查。检查或下载期间禁用重复请求。
- 发现比已下载版本更高的 Release 后，自动下载新的安装包并更新提示；相同或更旧的版本不会重复下载或降级。
- 检查失败时保留有效的已就绪包并显示错误。新包下载失败时明确进入错误状态，避免将可能失效的旧包显示为可安装。
- 手动与定时检查合并为同一个请求；检查期间暂停空闲安装，真正退出前再次验证版本、用户安排和 Agent 运行状态。
- 处理迟到下载事件、重复错误事件及取消安装竞态，避免旧目标覆盖新目标。
- 改进更新卡片的忙碌提示、错误详情、键盘操作和窄面板布局。

根工作区/Electron：1.17.1。已有旧版本客户端需要先安装本版，才能显示新增的手动检查入口。
