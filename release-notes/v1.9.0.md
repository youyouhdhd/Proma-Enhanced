# v1.9.0 — MCP 共享与远程访问产品化

本版将 MCP 设置改为以“共享哪些内容”为起点的完整流程，并让本机访问、远程连接和分析能力分别配置。

## 主要变化

- 统一管理受管工作区、本地项目和额外文件夹；显示真实路径健康状态，保留现有 workspace_id。
- 工具目录依据只读能力和开关动态生成。共享内容与远程子集热更新，无需重新建立隧道；连接参数变化会提示重连。
- 增加 Tailscale Funnel、ngrok 和 External HTTPS，保留 Cloudflare Quick / Named；OpenAI Secure Tunnel 明确列为实验性。
- 新增默认关闭的 PROMA 异步只读分析：选择渠道和模型后启用，支持状态、结果与取消，单并发和有限队列避免重复消耗。
- 连接故障显示降级诊断，不因一次检测失败终止隧道。配置与运行状态通过事件同步，轮询作为后备。
- 保留稳定 Secret，区分地址变更与工具定义变更；只有定义变化才提示 Refresh。

## 升级与使用

旧公网共享子集会保留为自定义范围。先确认共享根及读取权限，再选择 Provider、填写所需程序与凭据，保存并启动。公网 Ready 后复制授权 URL 到 ChatGPT，完成 Scan Tools。额外程序由用户安装或选择，本版不自动安装网络服务。

直接文件/Git 读取不会调用 Proma 模型；启用分析任务后会使用所选渠道额度。分析不能写文件、执行 Shell 或递归委派。重启不会自动重跑中断任务。

## 验证边界

自动化覆盖配置迁移、目录边界、动态工具、队列去重与取消、热更新、故障降级及 Git 外部执行防护，使用模拟运行器，不消耗模型 API 额度。完整构建和发布状态以对应 Actions 结果为准。

Cloudflare Quick 的真实 ChatGPT Scan Tools / 工具调用通过情况来自用户在 V11 文档中的验收反馈。Named、ngrok、External HTTPS 的真实公网验收尚未完成，Tailscale 为 Beta，OpenAI 为实验性；不能将脚本模拟通过理解为所有 Provider 已完成端到端验收。

实现、复现命令和维护边界见 [V11 开发记录](../docs/mcp-v11-implementation.md)。
