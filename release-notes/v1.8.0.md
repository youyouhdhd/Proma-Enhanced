# v1.8.0 — V10 Public HTTPS 与可替换的 MCP Transport

本版让 Proma 通过标准 Public HTTPS 接入 ChatGPT：新增 Cloudflare Quick / Named，OpenAI Secure Tunnel 保留为实验性选项。依照用户确认，先交付完整功能测试版，再进行安装后的 ChatGPT / Named 人工验收。

## 新的远程连接方式

- **Cloudflare Named（日常推荐）**：稳定 HTTPS 域名，固定 Public Ingress 端口，Secret 与 token 加密保存，重启后保留同一 Server URL。
- **Cloudflare Quick（快速测试）**：生成临时 HTTPS 地址。必须通过公网官方 MCP Client 检查后才显示 Ready；每次启动 URL 会变化。
- **OpenAI Secure Tunnel（实验性）**：保留原有 Runtime Key、Doctor、readyz、V9 流量归因和日志入口；Discovery 后未继续 tools/list 时提示切换 Public HTTPS。
- **Local Only**：仅运行本机 MCP，不启动新的公网 Transport。

产品只支持 PATH 检测和选择已有 cloudflared 程序，不自动下载。原先未经验证的 OpenAI 自动安装源已移除，旧安装调用会明确返回停用提示。

## Public Ingress 与权限

- 独立监听 localhost，默认固定端口 8787；冲突明确报错，不自动换端口。
- 仅支持 modern stateless MCP，保留 Local MCP 原有 Legacy 兼容。
- 公网固定开放 10 个只读工具。即使内部项目允许写入，公网仍拒绝 write_file、edit_file 和 shell_execute 的直接调用。
- 公网项目单独勾选，默认不公开任何项目；同时受内部读取权限、实时工作区解析和原有路径边界约束。
- 32 字节随机 Connector Secret 由 safeStorage 加密持久化；完整 URL 仅在用户点击复制时由主进程写入剪贴板，不进入 renderer 状态、普通日志或诊断导出。
- Named token 只经 TUNNEL_TOKEN 环境变量传递。cloudflared 使用独立配置和 HOME，避免继承用户其他 ingress；不使用 shell，不自动更新程序。
- OpenAI 控制面代理与 localhost 访问分离；新配置默认不自动公开项目，自动恢复需用户明确启用。

## 如何测试

1. 完全退出旧版，包括托盘，再安装本版。
2. 打开“远程 MCP”，准备官方 cloudflared，选择 PATH 或已有程序。
3. 在本机项目管理中配置读取授权，再单独勾选公网只读项目。
4. 选择 Quick，等待公网官方 Client 验证通过，复制 ChatGPT Server URL。
5. ChatGPT 选择 Server URL / No Authentication，Scan Tools 后测试列出项目、读取README和Git状态。
6. 日常切换 Named：配置稳定域名、Tunnel Token，以及 Cloudflare Published Application 的 localhost origin；验证重启后同一 App 仍可调用。

## 人工验收边界

本版为预发布。真实 ChatGPT Scan Tools / App 创建、安装后界面操作，以及 Named 真实域名的重启复用，按用户安排由安装后人工验收。模拟测试和公网官方 Client 结果不冒充这些结果。

Secret URL 本身具有所选项目的读取授权；请使用主进程复制按钮，不手工复制界面上的脱敏地址。轮换 Secret 会使旧 URL 失效。公网写入、OAuth 2.1 和 Codex delegation 不属于本版。

完整实现、Gate 记录与复现命令见 [V10 开发记录](../docs/mcp-v10-gates.md)。
