# v1.13.2 — 待审批任务队列边界修复

本补丁版修复 Agent Action 队列在 `maxQueued=0` 时忽略 `waiting_approval` 任务的问题，避免远程请求在本地审批模式下无限堆积待处理动作。

- queued、planning、running、waiting_approval 统一计入任务容量限制。
- `maxQueued=0` 仍表示并发满时拒绝新的任务，并新增待审批状态回归测试。
- 保留 v1.13.0 的 ChatGPT 能力发现与 Agent Action，以及 v1.13.1 的 Direct/Agent 执行租约来源隔离。

版本：Electron 1.13.2；shared 0.8.1；根工作区 1.1.1；Bridge 13；Pi 0.85.1。

验证：708 tests pass / 0 fail；全 workspace typecheck、Electron build、`bun install --frozen-lockfile` 通过。
